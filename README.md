## 🎯 What This Tool Does

CTExcel SMS DJI is a simple Windows application that helps you send text messages through a CTExcel mobile plan using a DJI QDC507 device. It provides a clean, easy-to-use web interface right on your computer, and optionally connects to Telegram so you can send messages from your phone too.

Think of it as a bridge between your computer and your mobile SIM card. If you have a DJI QDC507 (a small cellular modem device) and a CTExcel SIM card, this tool lets you type messages on your computer and send them like you would from a normal phone.

## 🤖 Optional: Setting Up the Telegram Bot

If you want to send SMS from your phone through Telegram, you can enable the bot feature. This is optional but very handy when you're away from your computer.

### What You'll Need for Telegram:

- A Telegram account (free to create)
- The Telegram app on your phone

### How to Enable the Bot:

1. Open Telegram and search for "BotFather" (this is the official bot creator)
2. Start a chat and type `/newbot`
3. Follow the instructions to create a bot
4. Copy the bot token (looks like a long string of numbers and letters)
5. Open the CTExcel SMS DJI web interface
6. Go to Settings
7. Paste the bot token into the "Telegram Bot Token" field
8. Click Save

Now you can message your bot in Telegram to send SMS. Just type the phone number and message text, and it will be delivered through your device.

## 🛠️ Troubleshooting Common Problems

### Device Not Detected

- Make sure the USB cable is firmly connected
- Try a different USB port on your computer
- Check that Windows recognizes the device in Device Manager

### Messages Not Sending

- Verify your SIM card has credit
- Check the phone number format (include country code)
- Make sure you're in an area with cellular signal

### Web Interface Won't Open

- Confirm the application is running (check system tray)
- Type `http://localhost:8080` manually instead of clicking
- Close and restart the application

### Telegram Bot Not Working

- Double-check the bot token is entered correctly
- Make sure you've chatted with your bot at least once
- Restart the application after changing settings

If problems continue, check the repository's issues page on GitHub for known problems and solutions from other users.
